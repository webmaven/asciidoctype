== [Unreleased]

=== Changed

* Updated `asciidoctrine` dependency constraint to `>=0.2.0a4`.

=== Fixed

* Fixed table column proportions (`[cols="..."]`) to emit proportional `<colgroup>` with `<col style="width: ...;">` and semantic cell alignment classes (`halign-*`, `valign-*`) in HTML5 and XHTML templates (Issue #3).

== [0.1.0a3] — 2026-08-22

=== Added

* Support for injectable syntax highlighter callable in `AsciiDoctypeRenderer` via optional `highlighter: HighlighterCallable` parameter (`Callable[[str, str], Optional[str]]`) for custom server-side syntax highlighting (e.g. Pygments).
* Exported `HighlighterCallable` in public API `asciidoctype`.
* Added `extract_text` and `highlight_code` helper utilities on `AsciiDoctypeRenderer`.
* Added candidate resolution mapping `source` nodes to `["source.html", "listing.html"]`.

=== Fixed

* Fixed `listing.html` (HTML5 and XHTML) to evaluate `renderer.highlight_code(node, ctx)` and fall back to rendering both `node['inlines']` and `node['value']` cleanly (resolving Issue #1).
* Fixed GitHub Pages deployment workflow in `.github/workflows/pages.yml` by removing unauthorized `enablement: true` flag.

== [0.1.0a2] — 2026-08-17

=== Added

* Static zero-JS E2E showcase galleries for HTML5 (`examples/gallery/index.html`) and XHTML (`examples/gallery/index-xhtml.html`) showcasing all 39 ASG node types with interactive CSS tab navigation.
* GitHub Actions workflow (`.github/workflows/pages.yml`) to automatically deploy the showcase galleries to GitHub Pages.
* `asciidoctype.linter` module for auditing custom Chameleon templates against insecure `structure` directives and syntax errors.
* Security enhancements to `AsciiDoctypeRenderer`: `strict` mode, `validate_templates` startup auditing, and `max_depth` recursion depth guards.

=== Changed

* Upgraded `asciidoctrine` dependency constraint to `>=0.2.0a1` taking advantage of upstream parser fixes for quote/verse attribution, list continuations (`+`), code listing callouts, page breaks (`<<<`), and document footnote catalogs.
* Updated `html5/document.html` and `xhtml/document.html` to render document-level footnote bibliographies from the resolved `footnotes` ASG collection.
* Updated `footnote.html` templates to support sequential `index` fields and standard `_footnote_{id/index}` anchor IDs.
* Updated `callout.html` and `calloutListItem.html` to support numeric `value` fields and render semantic `.conum` circular badges.

== [0.1.0a1] — 2026-08-11



Initial pre-release of AsciiDoctype.

=== Added

* `AsciiDoctypeRenderer` class with `target_format` validation (`html5`, `xhtml`).
* `AsciiDoctypeRenderingError` typed exception with node-name and pipeline
  diagnostics in the message.
* Chameleon `PageTemplateLoader` integration with ordered search path resolution
  and automatic core template fallback.
* Template override mechanism: downstream themes supply a `search_paths` list;
  custom templates take precedence over bundled core templates.
* Core HTML5 and XHTML 1.0 Strict templates for 39 node types (78 templates
  total):
** Block-level: `document`, `section`, `paragraph`, `listing`, `list`,
   `listItem`, `admonition`, `table`, `sidebar`, `example`, `quote`, `image`,
   `open`, `literal`, `verse`, `stem`, `passthrough`, `audio`, `video`,
   `collapsible`, `descriptionList`, `descriptionListItem`,
   `descriptionListTerm`, `calloutList`, `calloutListItem`, `floatingTitle`,
   `thematic_break`, `page_break`, `fallback_container`.
** Inline-level: `text`, `span` (strong / emphasis / code / mark / default),
   `ref`, `image_inline`, `footnote`, `kbd`, `button`, `menu`, `callout`,
   `break`.
* XHTML 1.0 Strict pipeline with XML declaration, DOCTYPE, namespace binding,
  and self-closing void elements.
* Native MathML rendering: `latex2mathml` converts LaTeX equations in `stem`
  and `passthrough` blocks to `<math>` MathML elements at render time. No
  downstream JavaScript dependencies needed.
* `pre-commit` integration with `.pre-commit-config.yaml` running `ruff`,
  `mypy`, and `pytest`.
* `bin/check.sh` concise verification script.
* TCK-style integration tests parsing real AsciiDoc source through
  `asciidoctrine` pipeline.
* Full pytest test suite: 42 tests across 17 test files.
* Comprehensive AsciiDoc documentation: `README.adoc`, `LICENSE.adoc`,
  `ARCHITECTURE.adoc`, `CONTRIBUTING.adoc`, `AGENTS.adoc`, `CHANGELOG.adoc`.
* Runtime dependencies: `chameleon>=4.0.0`, `asciidoctrine>=0.1.0a12`,
  `latex2mathml>=3.77.0`.
