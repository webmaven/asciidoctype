== [0.1.0a1] — 2026-08-11

Initial pre-release of AsciiDoctype.

=== Added

* `AsciiDoctypeRenderer` class with `target_format` validation (`html5`, `xhtml`).
* `AsciiDoctypeRenderingError` typed exception with node-name and pipeline
  diagnostics in the message.
* Chameleon `PageTemplateLoader` integration with ordered search path resolution
  and automatic core template fallback.
* Template override mechanism: downstream themes supply a `search_paths` list;
  custom templates take precedence over bundled core templates.
* Core HTML5 and XHTML 1.0 Strict templates for 39 node types (78 templates
  total):
** Block-level: `document`, `section`, `paragraph`, `listing`, `list`,
   `listItem`, `admonition`, `table`, `sidebar`, `example`, `quote`, `image`,
   `open`, `literal`, `verse`, `stem`, `passthrough`, `audio`, `video`,
   `collapsible`, `descriptionList`, `descriptionListItem`,
   `descriptionListTerm`, `calloutList`, `calloutListItem`, `floatingTitle`,
   `thematic_break`, `page_break`, `fallback_container`.
** Inline-level: `text`, `span` (strong / emphasis / code / mark / default),
   `ref`, `image_inline`, `footnote`, `kbd`, `button`, `menu`, `callout`,
   `break`.
* XHTML 1.0 Strict pipeline with XML declaration, DOCTYPE, namespace binding,
  and self-closing void elements.
* Native MathML rendering: `latex2mathml` converts LaTeX equations in `stem`
  and `passthrough` blocks to `<math>` MathML elements at render time. No
  downstream JavaScript dependencies needed.
* `pre-commit` integration with `.pre-commit-config.yaml` running `ruff`,
  `mypy`, and `pytest`.
* `bin/check.sh` concise verification script.
* TCK-style integration tests parsing real AsciiDoc source through
  `asciidoctrine` pipeline.
* Full pytest test suite: 42 tests across 17 test files.
* Comprehensive AsciiDoc documentation: `README.adoc`, `LICENSE.adoc`,
  `ARCHITECTURE.adoc`, `CONTRIBUTING.adoc`, `AGENTS.adoc`, `CHANGELOG.adoc`.
* Runtime dependencies: `chameleon>=4.0.0`, `asciidoctrine>=0.1.0a12`,
  `latex2mathml>=3.77.0`.
